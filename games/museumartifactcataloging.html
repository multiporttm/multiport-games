Museum Artifact Cataloging
Score: 0 | Hi: 0 ❤❤❤ Day 1
How to play: A new artifact arrives on the intake tray with a clue card. Click/tap the correct category, era, and storage bin buttons (or use 1-3 keys for category, Q/W/E for era, A/S/D for bin) to file it before its timer bar runs out. Each correct full match scores points and speeds up the queue; a wrong pick or an expired item costs a life. Lose all 3 lives and intake grinds to a halt. The queue gets busier — faster items, trickier cards — with every day.
