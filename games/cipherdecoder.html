Press Start to receive an encoded message
Each letter in the coded message has been swapped for another letter, consistently. Click a highlighted letter in the message (or its tile), then click a letter on the keyboard below to assign it as the decoded value — every matching letter in the message updates at once. Fill in the whole message and click Check Solution to submit. Solve it to unlock a longer, trickier cipher.
