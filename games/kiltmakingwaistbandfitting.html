Each customer's ticket shows a target Waist size, Pleat count, and Strap length. Use the + / − buttons (or keys 1/2 for waist, 3/4 for pleats, 5/6 for strap) to dial each value to match, then press Confirm Fit before the clock runs out. Exact matches score the most; close-but-off fits still pass with fewer points. Each new customer tightens the time limit.
