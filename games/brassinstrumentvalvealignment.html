Brass Instrument Valve Alignment
Level: 1 Lives: ♥♥♥ Score: 0 | Hi: 0
Select a valve, then align its port and height
Select a piston valve by clicking/tapping it or pressing its number key. Rotate its port with the Port Rotation slider (or Left/Right arrows, or drag on the dial) and set its finger-button height with the Button Height slider (or Up/Down arrows) so the two ports line up and the button sits level with the others. Press Test Valve (or Enter) to check it. Align every valve in the set before you run out of attempts — across more valves needing alignment as you level up!
