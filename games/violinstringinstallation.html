Violin String Installation
Score: 0 | Hi: 0 ❤❤❤ String 1/4
 
How to play: First, wind the string onto the peg: hold the mouse/finger down and move right, or hold the Right Arrow, to turn the peg — stop winding once the coil counter is inside the green target band, then release. Next, tension it: hold down / hold Up Arrow to pull the pitch up toward the target zone, then press Enter (or tap the Lock button) to set it — overshoot past the snap point and the string breaks, costing a life. Gut, synthetic, and steel strings each wind and snap differently, and the windows get tighter every round.
