Nerdle
Guess the 8-character equation!
Played: 0 · Streak: 0 · Best Streak: 0
How to play: A secret, valid 8-character math equation (digits 0-9 and + - * / =) is hidden — something like 12+34=46. You have 6 guesses. Every guess must be a valid, correct equation exactly 8 characters long. After each guess, each character turns green if it's in the right spot, purple if it's in the equation but the wrong spot, or gray if it doesn't appear at all. Use the on-screen keypad or your keyboard (digits, + - * /, =, Enter, Backspace).
