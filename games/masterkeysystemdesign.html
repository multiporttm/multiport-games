Master Key System Design
Score: 0 | Hi: 0 ❤❤❤ Building 1
How to play: Every door needs its own key code (shown on the door) to work, but the single Master Code at the top must also open every door. Each chamber has a Change slot (for that door's own key) and a Master slot (for the master key) — when a door's digit already matches the master digit at that chamber, only the Change slot is needed. Click a pin in the tray (or press its number key) to pick it up, then click a slot to install it; click a filled slot to return its pin. The pin supply is exactly enough to finish correctly, so wasting a pin on a slot that didn't need it will leave you short elsewhere! Use Check Fit any time to preview which doors would open, and click Finish Building (or press Enter) once every slot looks right, before the clock runs out. A bad finish or a missed deadline costs a life. Complete enough buildings to win; lose all 3 lives and the contract is lost.
