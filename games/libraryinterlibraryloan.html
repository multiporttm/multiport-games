Select a request, then click the branch that has it in stock.
Requests arrive faster and deadlines get shorter each wave.
How to play: Loan requests pile up in the queue, each needing a specific book. Click a request to select it, then click the partner branch whose shelf shows that book in stock to ship it there. Correct routing before the deadline bar empties scores points; a wrong branch or an expired deadline costs one of your 3 lives. Survive as many waves as you can as requests arrive faster. Keyboard: Arrow keys to pick a request, 1-5 to pick a branch.
