How to play: Each order asks for a fragrance strength (Parfum, EDP, EDT, or Cologne) at a target concentration percentage, for a given batch size. Use the concentrate and alcohol controls (or arrow keys) to set how much of each goes into the batch — the remainder fills automatically with water — so that concentrate ÷ batch size lands on the target percentage. Press Enter or click Submit Batch when ready, and Backspace to reset. You have 3 lives — missing the target or running out of time costs one. Target ranges get trickier and batch sizes grow larger as rounds climb.
