Press Start to plan recess!
How to play: Drag each class card onto an empty equipment slot for a time period. Each class shows its preferred equipment icons — match them for happy kids! Each piece of equipment can only hold one class per time slot (no doubling up). When every class is placed, click Finish Round to see your satisfaction score. More classes and equipment unlock each round.
