Model Train Coupler Install
Score: 0 Level: 1 Car: 1/5 Lives: 3 Hi: 0
The coupler's height needle swings up and down the gauge. Press Install (or Space, or tap) the instant the needle is inside the green tolerance band so the coupler locks at the right height. Miss the band and you lose a life. The band narrows and the needle swings faster as more cars join the train.
