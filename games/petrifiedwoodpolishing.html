Petrified Wood Polishing
Slabs: 0Best: 0Progress: 0%
 
Select a grit with the buttons, number keys 1-4, or move the cursor with Arrow Keys. Click/drag (or press Space) across the slab to sand it — each patch must be sanded Coarse → Medium → Fine → Polish in order. Using the wrong grit on a patch leaves a rough mark and fills the rough meter; fill it up and the slab is ruined. Bring every patch to a full polish to finish the slab.
