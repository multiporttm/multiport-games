Silkscreen Registration Aligning
Score: 0 | Hi: 0 ❤❤❤ Level 1 Time: 20
How to play: The base black layer is printed with fixed registration crosshairs (white). Each new color layer starts off-center with its own crosshair — use Arrow Keys (or the on-screen ↑←→ and drag) to nudge it until its crosshair sits over the base marks, then press Space / Enter / Lock Layer to lock it in. Lock while off-target and you ruin that layer. Register every color layer before the timer runs out to finish the print. More layers, a shorter clock, and a tighter tolerance arrive every round — ruin 3 layers and the run ends.
