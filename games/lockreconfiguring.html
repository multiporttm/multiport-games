Lock Reconfiguring
Score: 0 | Hi: 0 ❤❤❤ Lock 1
How to play: Each lock's chambers need new pin stacks that match the new key's bitting code shown above the cylinder. Click a pin in the tray to pick it up (or press its number key), then click an empty chamber to install it — click a filled chamber to take its pin back out. Fill every chamber with the correct length, then click Re-key Lock (or press Enter) before the timer runs out. Miss the deadline or submit a wrong pin and you lose a life. More chambers and decoy pins appear as you go — lose all 3 lives and the job is over.
