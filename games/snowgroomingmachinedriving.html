Snow Grooming Machine Driving
Score: 0 | Hi: 0 ❤❤❤ Run 1/6 Time: 60
How to play: Drive the snowcat with the Arrow Keys / WASD or the on-screen pad, making overlapping passes to groom moguls into smooth corduroy. Cover enough of the run before the timer hits zero and before you drift off the groomed edges too often. Each run gets bigger and the clock runs shorter — groom 6 runs with 3 lives to finish before the lifts open!
