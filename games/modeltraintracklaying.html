Model Train Track Laying
Score: 0 | Hi: 0 ❤❤❤ Board 1
 
How to play: Click/tap a track piece — or move the cursor with the Arrow keys and press Space/Enter — to rotate it 90°. Rotate every piece until a single unbroken track runs from the green start signal to the red end signal. Complete the layout before the time bar runs out — run out of time three times and the game ends. Later boards are bigger and add track switches, so plan the route carefully.
