Rip Current Identification
Score: 0 | Hi: 0
Watch the surf line for rip current tells: a choppy, discolored channel, a gap in the breaking whitewater, or foam streaming seaward. Tap the hazardous lane (or use Arrow Keys + Enter, or number keys) to flag it before the swimmer drifts in. Flag every rip each round — wrong flags and timeouts cost a life. 3 lives!
