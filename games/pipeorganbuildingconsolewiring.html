Select a console terminal, then its matching numbered relay terminal, and press Connect to run the wire.
How to play: The console's row of key contact terminals sits on top, and the relay cabinet's row of numbered terminals sits below. Move the selector with the arrow keys, A/D, the on-screen arrows, or by tapping a terminal directly, and press Connect (Enter, Space, or the on-screen button) on a console terminal to pick up its wire. Move the selector to the relay terminal sharing the same number and press Connect again to run a clean connection between them, which locks in and glows. Connecting a wire to a terminal with the wrong number sparks a short circuit and costs you time, so check the numbers before you commit. Wire every terminal correctly before the timer reaches zero to post a high score.
