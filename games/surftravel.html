Surf Travel

🏄 Ready to surf?

Surf Travel launches Microsoft Edge's built-in hidden surfing game. Click below to open it and start riding the waves.

🌊 Launch Surf Game
How to play: Click Launch Surf Game to open Microsoft Edge's built-in surfing game at edge://surf. If you're already browsing in Microsoft Edge, it opens right in a new tab. If you're using another browser but have Edge installed, clicking the button will try to launch Edge for you automatically and open the game there. Once it's open, use the Arrow Keys (or on-screen controls) to steer your surfer around obstacles and ride as far as you can.
