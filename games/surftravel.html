Surf Travel

🏄 Ready to surf?

Surf Travel launches Microsoft Edge's built-in hidden surfing game. Click below to open it and start riding the waves.

🌊 Launch Surf Game
How to play: Click Launch Surf Game to open Microsoft Edge's built-in surfing game at edge://surf. Use the Arrow Keys (or on-screen controls in Edge) to steer your surfer around obstacles and ride as far as you can. This game is a shortcut to a feature built into the Microsoft Edge browser, so it only opens correctly when viewed in Microsoft Edge.
