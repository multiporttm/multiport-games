Select the correct tool, then click the matching flaw.
Each antique has several visible flaws — cracks, tarnish spots, and missing pieces. Select the matching tool from the toolbar below (glue for cracks, polish for tarnish, mallet/patch for missing pieces) using mouse, tap, or the number keys 1-3, then click/tap the flaw to fix it. Use the wrong tool and the flaw stays broken! Restore every flaw before time runs out to complete the item — later items have more flaws and trickier matches.
