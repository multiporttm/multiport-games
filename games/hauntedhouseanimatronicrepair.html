Haunted House Animatronic Repair
Score: 0 | Hi: 0 ❤❤❤ Prop 1
How to play: Each broken animatronic has three components — Motor, Trigger Sensor, and Sound. Click/tap a component (or press 1, 2, or 3) to run its diagnostic test; a working part flashes green, the faulty one flashes red. Once you've found the fault, click/tap it again (or press the same number) to fix it before the attraction-opens timer runs out. Guess wrong and time ticks away — run out of time or misdiagnose too many props and you lose a life. More components get added and the timer shrinks as you repair more props. Lose all 3 lives and the haunted house stays dark!
