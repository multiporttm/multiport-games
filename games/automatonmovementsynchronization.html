Automaton Movement Synchronization
Level 1Score: 0Lives: 3Hi: 0
Select a part and tune its cam offset
Press the number keys or tap a body part on the automaton to select it, then use the Left/Right arrow keys for a fine nudge or Up/Down arrow keys for a coarse nudge of its cam offset (or use the on-screen buttons on touch). Every dial's hand sweeps around once per rotation — get all of them inside their glowing sync window at the same moment to assemble the movement. Three timeouts end the run — later rounds add more body parts to synchronize.
