Music Box Comb Tuning
Lives: 3Level 1Score: 0 | Hi: 0
Tune the glowing tooth to the target pitch
Left/Right select tooth · Up/Down file thinner/thicker · Space/Tap lock in
File a music box comb's metal teeth to tune each one to the correct pitch. Use Left/Right or A/D to pick a tooth, Up/Down or W/S to file it thinner (sharper) or thicker (flatter), and Space or Tap to lock it in. Combs get longer and target pitches trickier as you level up.
