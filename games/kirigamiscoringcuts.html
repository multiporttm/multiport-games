Kirigami Scoring Cuts
Score: 0 | Hi: 0 ❤❤❤ Sheet 1
How to play: Press and hold (mouse / finger / Space) to push the scoring blade's pressure up, release to ease it off. Drag the tool along each dashed fold line (or let it auto-advance while held) keeping the gauge needle inside the green safe zone the whole way. Too little pressure and the fold line never scores; let the needle run into the red and you slice clean through, ruining the sheet. Finish every line to flip to a fresh sheet — the safe zone narrows and more lines appear each round. Lose all 3 lives and it's game over!
