Ship in a Bottle Rigging Tensioning
: 1 : 0 Hi: 0
How to play: Each thread's gauge slowly drains. Press and hold (mouse, finger, or Tab+Space / number keys 1-9) on a thread to pull it taut into the green zone — keep holding and it will snap, so release in time! Let any thread fully slacken too long and the ship's rigging fails. Survive the round timer; each round adds more threads and a tighter green zone.
