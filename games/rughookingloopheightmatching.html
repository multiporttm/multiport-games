Rug Hooking Loop Height Matching
❤️❤️❤️ Score: 0 | Hi: 0 Row 1
A wool loop rises and falls on the hook as you pull it through the backing. A gold target line marks the exact height this loop in the row needs to match. Press Space, tap, or click 🧶 Set Loop the instant the loop height crosses the target to lock it in place. Pulling too high snags the yarn, pulling too short leaves a bald spot — three bad loops and the row is scrapped! Lock every loop in a row to move on to a tighter row.
