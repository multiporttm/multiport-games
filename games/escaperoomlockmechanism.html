Escape Room Lock Mechanism
Score: 0 Level: 1 Hi: 0 Lives: ●●●
Each wired input shows a clue. Click/tap an input to cycle its value, or use Left/Right Arrows to select an input and Up/Down Arrows (or Space) to cycle its value, until every input matches its clue exactly. Press/tap Test Lock (or Enter) to try releasing it — testing before every input matches costs a life. Three lives, and more inputs get wired in every level.
