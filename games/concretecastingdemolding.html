Concrete Casting Demolding
Mold: 1 Integrity: 100% Score: 0 Best: 0
Mallet force: 50
Set the Mallet force slider (or use Up/Down arrows) to roughly match each glowing release point's required force, then tap/click that point (or press Space/Enter) while it glows to knock the form loose. Too weak and it will not budge, too strong or mistimed and the cast cracks — work around the whole mold before the sequence timer runs out to demold it cleanly. Later molds add more release points and tighter force windows.
