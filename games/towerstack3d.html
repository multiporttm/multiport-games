🗼 Isometric Tower Stack 3D
Drop each sliding block onto the tower. Line it up well and the tower keeps its width; overhang gets sliced off and tumbles away. Miss completely and it's game over.
Click, tap, or press Space/Enter to drop the sliding block onto the tower below it. Only the part that overlaps the block beneath stays — the rest is cut away and falls off. Keep stacking without missing entirely: each landing narrows the margin for error and speeds up the slider.
