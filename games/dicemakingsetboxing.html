Dice Making Set Boxing
❤️❤️❤️ Score: 0 | Hi: 0 Set 1
A finished die drops from the packing chute toward a presentation box with six numbered slots, and it has to land in the slot matching the number showing on its top face. Use the Left/Right arrow keys, drag, or tap ◀ Shift / Shift ▶ to slide the falling die sideways over the slots before it reaches the bottom of the box. Guide it into the matching slot to box it neatly and score points, but let it land in the wrong slot — or miss the box entirely — and that die is scrapped, costing you a life. Three scrapped dice and the whole set is ruined! Box every die in a set to move on to a bigger set with narrower slots and a faster drop.
