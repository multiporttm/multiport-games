Drag the sliding guide ring along the rod and release it exactly on the marked spacing point to whip it on tight.
Drag the line guide ring left and right along the rod blank (mouse, finger, or Left/Right arrow keys) and release it exactly on the glowing marked spacing point to whip it onto the rod. Each rod needs several guides placed in order from butt to tip; a tight release scores big and lights the guide, a sloppy release still attaches but dents Rod Quality. Let Rod Quality run out and the rod is scrapped.
