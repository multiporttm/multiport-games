Pocket Watch Repair: Hand Fitting
Score: 0 | Hi: 0 ❤❤❤ Watch 1/8
How to play: The pale ghost hands on the dial show the correct reference time. Click/tap a hand button (or press 1, 2, 3) to select hour, minute, or second hand, then drag around the dial (or use Left/Right Arrow Keys) to rotate it onto its matching ghost hand. Get every hand within tolerance at the same time to fit the set — but if two hands ever swing within a hair of each other they snag and you lose a life! Each new watch adds a tighter tolerance, and later watches add the second hand too.
