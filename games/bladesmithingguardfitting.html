Bladesmithing Guard Fitting
Score: 0 | Hi: 0 ❤❤❤ Guard 1/8
How to play: The diagram shows the marked target position for the guard on the tang. Press and hold File Metal (or Arrow keys / tap-and-hold the button) to widen the guard's slot — the fit gauge needle moves right as you file. Release before it overshoots the glowing safe tolerance band, then press Seat Guard (or Space) to lock it in. Land inside the band for a flush fit; undershoot and it will not seat, overshoot and it leaves a gap. Each guard shape narrows the safe band!
