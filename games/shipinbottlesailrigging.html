Ship in a Bottle Sail Rigging
Ships Rigged: 0 Score: 0 Hi: 0
Click a glowing spool, then click its matching numbered cleat.
How to play: Each numbered spool must be rigged to the cleat with the same number, in order from 1 upward. Click (or tap, or use arrow keys + Enter to move focus) the glowing spool, then click its matching cleat to run the thread — right pair and the line is tied off; wrong cleat snaps the thread and costs time. Finish every line before the glue-setting timer bar runs out to complete the ship. Each new ship adds more rigging lines.
