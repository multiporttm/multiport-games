Marionette String Rigging
Level: 1 Score: 0 | Hi: 0 ♥ ♥ ♥
Click/Tap a glowing body point, then Click/Tap the matching slot on the control bar above it to rig that string. Wrong matches cost a life. You can also use Arrow Keys to move the cursor and Enter/Space to select — Esc cancels a pick. Rig every string before the timer bar empties, then watch the test wiggle before the next, harder round!
