Rail Yard Shunting Puzzle
Score: 0 Yard: 1 Lives: ❤❤❤ Moves: 0/0 Hi: 0
Click/tap a yard track to pick up its last railcar, then click/tap another track to move it there, or click/tap the green Departure track to send it out (only if it's the next number in order!). Keys 1-4 select the yard tracks, D or 0 targets departure, Esc deselects. Sort every car into order before you run out of moves!
