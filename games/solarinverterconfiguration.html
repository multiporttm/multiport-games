Each install spec lists a required voltage window, grid frequency and trip/power-factor setting. Drag each slider — or Tab between them and use the Arrow keys — until every value sits inside its green tolerance band, then click Lock In Configuration (or press Enter) before the timer runs out. Later installs add more parameters and tighter tolerances!
