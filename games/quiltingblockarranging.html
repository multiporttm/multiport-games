Quilting Block Arranging
Score: 0 Round: 1 Lives: ❤❤❤ Hi: 0
Check the small reference pattern at the top to see where each block belongs. Click/tap a block in the tray (left) to select it, press R to rotate it, then click/tap the matching empty slot (right) to place it. You can also use Tab to cycle tray selection and Arrow Keys + Enter to pick a target slot. Placing a block in the wrong spot or wrong rotation costs a life. Clear the grid to move to a bigger one!
