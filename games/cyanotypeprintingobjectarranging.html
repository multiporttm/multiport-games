Drag each object onto the outline that matches its shape, or select one and move the cursor with arrows then press Enter.
How to play: The coated sheet on the table shows faint grid outlines, each one shaped like a leaf, fern, key or feather, marking exactly where that object belongs in this round's composition. Drag an object up from the tray at the bottom with the mouse or your finger and drop it onto the outline that matches its silhouette, or press the number keys (or the Next Object button) to select an object, use the arrow keys to slide the highlighted cursor across the grid, and press Space or Enter (or the Place button) to set it down on the cell underneath the cursor. Dropping an object on the wrong outline or an empty cell does nothing and wastes a moment. Place every object on its correct outline before the placement timer runs out to lock in a clean composition and move on to a larger layout with more objects and less time. Arrange as many compositions as you can before time runs out on a round to set a new high score.
