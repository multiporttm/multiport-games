Bird Wing Spreading
Score: 0 Round: 1 Lives: ❤❤❤ Hi: 0
Drag a wing's wire handle (mouse/touch) — move left/right to adjust its angle and up/down to adjust feather spread — or select a wing with Tab and nudge both with the Arrow Keys. Match the faint reference silhouette on both wings, then press Enter/Space to set the mount before it dries. Tolerance tightens each round.
